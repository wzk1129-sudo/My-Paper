# Implementation audit: PDC-StructSup-BCA V1

Parent commit: `33d32b0d42b207ac5e8726ac427e2fc06093cffc`. Branch: `experiment/rddm-meddino-pdc-structsup-v1`. Formal RDDM source, Fast64 split, and Full-L333 evaluator hashes match `FINAL_AUDIT.json`.

Training path: `meddino_pdc_structsup_v1.train` → `StructSupTrainState.update` → unchanged `context_2p5d.model.training_loss` → unchanged residual diffusion `pred_res` MSE. The RDDM backbone takes the Direct 2.5D input and is trainable. PDC-Gated-BCA anatomy, PiDiNet-style PDC, gate, beta fusion, BCA128/64, alpha, EMA, optimizer and augmentation remain inherited. Frozen MedDINO supplies anatomy hints. The new provider subclasses `PDCFusionProvider` and preserves its S128/S64 restoration output. It adds `head128: Conv2d(64,1,1)` and `head64: Conv2d(128,1,1)` from **gated PDC shape** `y128/y64`, before beta fusion, with 194 trainable parameters total. Output shapes are [2, 1, 128, 128] and [2, 1, 64, 64] at batch 2.

Targets are generated **only from paired center NDCT during training**: [0,1] → HU=`4096*x-1024` → clip [-1000,1000]/1000 → Gaussian sigma1 kernel5 with reflect padding → fixed Scharr X/Y (coefficients /32) → sqrt(gx²+gy²+1e-12)/sqrt2 clipped [0,1] → area downsample to 128/64. See `STRUCTURE_TARGET_AUDIT.md`. They never enter the model forward or validation. Structure losses are L1 at both scales. A hook on the existing diffusion model output captures `pred_res` from the same forward, then uses `pred_clean=(2*LDCT-1)-pred_res` for the explicitly requested clean-image L1. No second diffusion forward, no new prediction branch, no noise objective, no output-edge loss. Total loss is original residual MSE + 0.02*L1(128) + 0.02*L1(64) + 0.02*L1(clean image). The three weights were fixed after final 20-step smoke; formal training did not adjust them.

The first queue failed at Python import before any optimizer step (`numeric_activity` imported from the wrong module). The original failed status/log remain. The corrected retry passed static imports and independently started from step 0, then reached 6000 steps. `SMOKE_RESULT_FINAL.json` is the accepted 20-step smoke; the earlier preliminary smoke without image L1 is retained separately and excluded from formal selection.

Parameter count: 99,737,431 total, 14,095,447 trainable. MedDINO frozen; PDC, gate, beta, BCA, alpha, RDDM and new heads trainable. All 15 audited gradient groups were nonzero in every formal step. Full L333 uses step6000 EMA and the frozen 2-step sampler. No training during Full-L333. This comparison changes side supervision **and** the optional clean-image L1 relative to PDC-Gated-BCA, so the observed delta cannot be attributed solely to the side heads.
