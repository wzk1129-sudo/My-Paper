# MedDINO 特征有效性审计 V1：最终报告

日期：2026-10-09。对象为 Official RDDM 2.5D + MedDINOv3 Condition V1 的 step_8000 EMA，固定 L333-fast64（64 张）。本轮没有训练、反向传播、优化器、EMA 更新或参数修改。所有新增文件均位于本审计目录。

## 1. 执行与验收

静态协议核验、四项合成数据单元测试、前两张切片的 A/B/C 冒烟、64 张 C0_NORMAL 基线复现、完整 A/B 特征审计和 C0–C6 条件干预均已完成，验收 **PASS**。相同模式重复运行首张切片的预测哈希一致。原始 V1@8k EMA checkpoint SHA256 为 1ea09e9d0a4f2d56a636a62dc4a02afe80ff6342f506628077dd0003af748ce1；MedDINO 权重 SHA256 为 492b2b96c00e9d3b93ba3b07a8d387aa2196b5e04698378fcc23049b447966d2。RDDM、FiLM、Adapter/Fusion、MedDINO 和全模型在本任务前后的张量哈希逐项相同。新代码、源文件和访问校验见 AUDIT_MANIFEST.json、POSTRUN_INTEGRITY.json。

C0 使用原 evaluate.validate 和正式 slice_metrics()，复现 PSNR 40.908237245 dB、SSIM 0.948847464、RMSE 18.119234 HU、MAE 11.986737 HU，四项与既有 DIAGNOSTIC_NORMAL.json 一致。自写干预评估的 C0 逐切片 PSNR/SSIM 与原 evaluator 的 C0 相差均小于 1e-8。C1_OFF 与历史条件关闭指标精确一致；C2_NEAR_SWAP 的 PSNR 与历史 SHUFFLED_MEDDINO 仅差 0.000000622 dB，供体仍严格沿固定相邻二元组；这点微差与旧评估将两条供体一起提特征、此处单条提特征的浮点实现路径相容，不改变下面的量级判断。

数据守卫只允许 64 个 Fast64 中心及其 LDCT 邻居；L506、external-memory、训练患者、neighbor NDCT 的实际打开数均为 **0**，blocked attempts=0。NDCT 仅用于 A/B 离线比较和事后评价，不传给阶段 C 的 RDDM 或 MedDINO 条件。POSTRUN_INTEGRITY.json 进一步核验 64 个 manifest 索引、固定种子、C2/C3 供体、C1 九处 FiLM 关闭、C6 仅 E2 条件发生变化。目录没有保存 CT 图像、特征张量或模型权重。

## 2. 阶段 A：跨剂量稳定性

相同坐标 LDCT/NDCT Token 的逐切片均值如下。前景由中心 LDCT 的 HU>-500 定义；软组织为 [-160,240] HU 且在前景内。区域在 512×512 上用 16×16 非重叠平均池化，覆盖比例≥0.5 的 Token 生效。这是强度近似，不是器官分割。余弦和相对 L1 均以 float32 计算；相对 L1 分母为 NDCT 特征平均绝对值，epsilon=1e-8。

| 特征 | 前景 cosine | 前景相对 L1 | 软组织 cosine | 软组织相对 L1 |
|---|---:|---:|---:|---:|
| 原始 L2 | 0.9599 | 0.4136 | 0.9586 | 0.4220 |
| 原始 L5 | 0.9665 | 0.3287 | 0.9653 | 0.3348 |
| 原始 L8 | 0.9687 | 0.2464 | 0.9676 | 0.2510 |
| 原始 L11 | **0.9770** | **0.2254** | **0.9764** | **0.2286** |
| 已训练 Adapter/Fusion | 0.8077 | 0.5938 | 0.8015 | 0.6041 |

**Q1：**L11 在两种区域都具有最高同位置余弦和最低相对 L1，是本次跨剂量一致性最强的原始层。该结果不单独证明临床结构有效。

## 3. 阶段 B：空间位置区分

前景查询与同一位置 NDCT Token 匹配；困难负样本为 Chebyshev 距离 1–2 的其他前景 Token，远距离负样本为欧氏距离≥8 的其他前景 Token。候选库为同一切片全部有效 NDCT 前景 Token。下表是先按切片计算，再对 64 张切片取均值；Top-1/Top-5 不是跨患者独立统计。

| 特征 | 前景困难 margin | 前景远距 margin | 前景 Top-1 | 前景 Top-5 | 软组织 Top-1 |
|---|---:|---:|---:|---:|---:|
| L2 | 0.0141 | 0.0243 | 55.21% | 73.67% | 52.77% |
| L5 | 0.0301 | 0.1614 | 92.53% | 99.65% | 92.10% |
| L8 | **0.0439** | 0.3090 | 98.39% | 99.87% | 98.30% |
| L11 | 0.0311 | **0.3412** | **99.85%** | ≈100% | **99.84%** |
| 已训练 Adapter/Fusion | -0.0131 | 0.0419 | 35.89% | 64.66% | 33.34% |

**Q2：**L8 对紧邻错误位置的平均 margin 最大；L11 的远距 margin 和 Top-1/Top-5 最好。相邻解剖区域本来相似，因此困难 margin 不能机械当成临床质量分。固定配准坐标和 ViT 位置编码也可能帮助同坐标检索；本轮没有位置先验消融，不能把 99.85% 全归因于解剖辨别能力。

**Q3：**按本审计定义的跨剂量一致性和同坐标检索，已训练 Adapter/Fusion 明显弱于原始 L8/L11：前景 cosine 从 L11 的 0.9770 降至 0.8077，Top-1 从 99.85% 降至 35.89%，困难 margin 由正变负。这表明融合表示未保留原始层在此诊断中的同位置可辨性；但 Adapter/Fusion 的训练目标是重建，不是跨剂量检索，不能据此断言它损害了 V1 重建。

## 4. 阶段 C：已训练 V1 对条件的利用

每组只改变指定的 MedDINO→FiLM 条件；2.5D LDCT、权重、2-step 采样和每片 seed=20260829+slice_index 固定。主指标复用正式 slice_metrics()。下列 Δ 是相对 C0 的 64 张逐切片均值；95% CI 为固定 seed 的 10,000 次**配对切片 bootstrap**，仅描述单个 L333 患者内部切片变化，不是跨患者显著性证据。区域误差采用相同 HU 主窗口；高梯度区域由中心 LDCT 的 Gaussian σ=0.8 + Scharr、前景内 top 10% 定义。

| 干预 | PSNR dB | ΔPSNR dB [95% CI] | ΔSSIM | ΔRMSE HU | PSNR 改善切片 |
|---|---:|---:|---:|---:|---:|
| C0 正常 | 40.908237 | 0 | 0 | 0 | 基线 |
| C1 九处 FiLM 关闭 | 40.762979 | -0.145259 [-0.163775,-0.128143] | -0.001419 | +0.296194 | 0/64 |
| C2 相邻二元组交换 | 40.902731 | -0.005507 [-0.008000,-0.003236] | -0.000047 | +0.011636 | 16/64 |
| C3 Fast64 最远 LDCT 供体 | 40.664033 | -0.244204 [-0.268189,-0.221506] | -0.002174 | +0.507446 | 0/64 |
| C4 全 stage 融合特征平移 2 Token | 40.862010 | -0.046228 [-0.055144,-0.038232] | -0.000507 | +0.094614 | 0/64 |
| C5 保留各通道空间均值、广播成常量图 | 40.802390 | -0.105847 [-0.126019,-0.087056] | -0.000944 | +0.214083 | 0/64 |
| C6 仅 E2 平移 2 Token | 40.897120 | -0.011117 [-0.014425,-0.008237] | -0.000133 | +0.022792 | 6/64 |

**Q4：**远距交换比相邻交换额外降低 PSNR 0.238697 dB（配对切片 bootstrap 95% CI [-0.262500,-0.216036]）；64/64 张远距交换的 PSNR 变化都比相邻交换更差。供体均来自固定 Fast64 的 LDCT，绝未用供体 NDCT。远距错配不仅改变局部解剖，也改变整体 slice 位置与全局信号，因此不能独立归因为局部结构。

**Q5：**C5 在保持融合特征每通道空间均值的情况下下降 0.105847 dB，支持 V1 利用了空间分布，不只是通用全局调制。C4 下降 0.046228 dB，C6 仅改 E2 仍下降 0.011117 dB（58/64 张恶化），证明 E2 空间位置有可测作用。C4 的非循环 replicate 平移会略改变全图均值，故 C5 是判断“删除空间分布”的更干净对照。C0 的条件更新 RMS/base RMS 在 E2≈0.1658、E1≈0.1352、D1≈0.1258，MID≈0.0070；这些幅度不是每处的因果收益。

区域误差方向与主指标一致：C3 的前景/软组织/高梯度 RMSE 分别比 C0 增加 0.7043/0.6131/1.0174 HU；C5 分别增加 0.3082/0.2664/0.4798 HU；C6 分别增加 0.0384/0.0354/0.0462 HU。完整 MAE、区域指标、每片变化、所有 stage 的更新比值见 CONDITION_INTERVENTIONS.csv 和 PER_SLICE_INTERVENTIONS.csv。

## 5. 科学结论与下一步

**Q6：选 D。**原始 MedDINO 高层在同位置跨剂量比较和位置检索中有明显信号；现成 V1 在关条件、错配、去空间分布、只动 E2 的干预下均受损，说明它确实使用了条件及其中的空间排列。已有严格匹配的旧训练对照在 8k 为 V1 比无 MedDINO 2.5D Control **+0.018291 dB**、SSIM +0.000180、RMSE -0.036778 HU，但 MAE +0.002241 HU；收益存在而较小。C1 关闭已训练模型的条件会破坏共同适配状态，-0.145 dB 不能当成 MedDINO 相对独立 Control 的训练增益。

**已确认：**L11 跨剂量最稳；L8 对紧邻错误位置 margin 最强；在本诊断中 Adapter/Fusion 削弱了同坐标跨剂量匹配；V1 对空间条件有可测依赖。**未验证：**这些 Token 的高 Top-1 有多少来自位置编码/固定配准，融合表示较低匹配率是否导致了重建增益受限，以及是否能跨患者重现。单个 L333 患者内的切片 bootstrap 不能替代跨患者验证。

论文层面可主张“空间条件确实被利用，且 matched 8k 增益有限”；不可主张“MedDINO 在 LDCT 表征失效”或“改进融合必然提高 PSNR”。**目前不建议立即再开训练。**最有根据的一个后续修改位置是四层 Adapter/Fusion：若后续独立患者只读验证仍见原始 L8/L11 强匹配而融合后明显下降，可只设计一个保留这些层局部可辨性的融合对照；不优先更换 MedDINO 主干或直接增加 Cross-Attention。本轮没有启动该实验。
